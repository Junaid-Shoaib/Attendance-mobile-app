# Android Native Project

This mirrors the standard files generated by `npx react-native init` for
RN 0.75 (Kotlin + new Gradle plugin DSL), hand-authored for this delivery.

## Before your first build

A few binary/generated artifacts can't be included in a source ZIP and
need to be generated locally:

```bash
# 1. Generate the Gradle wrapper jar (or just run ./gradlew once you have
#    Gradle installed globally — it will bootstrap itself)
gradle wrapper --gradle-version 8.8

# 2. Generate a debug keystore for local builds
cd app
keytool -genkeypair -v -keystore debug.keystore -storepass android \
  -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000

# 3. Add real app icons (currently placeholders) — use Android Studio's
#    Image Asset Studio or https://romannurik.github.io/AndroidAssetStudio/
#    and drop the generated ic_launcher.png / ic_launcher_round.png into
#    each res/mipmap-* folder.

# 4. Add your Firebase config file for push notifications
#    Download google-services.json from the Firebase console and place it
#    at android/app/google-services.json
```

## Build & run

```bash
cd ..            # project root (frontend/)
npm install
npm run android
```
